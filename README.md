## About Me

I am a data professional based in Australia, focused on building reliable, scalable data pipelines on Microsoft Azure.

My experience spans the full data lifecycle:

| Role | Focus |
|---|---|
| **Software Engineer** | Building and maintaining applications, writing clean, tested code and working with version control |
| **Data Analyst** | Turning business data into reports and insights using SQL, Python and dashboards |
| **Data Scientist** | Exploring data, building statistical and machine learning models, and communicating findings |
| **Data Engineer** | Designing ingestion pipelines, data models and audit frameworks on Azure |

Along the way, I have worked with retail sales data for community stores at Monash University and with complaints and audit data at ResMed. I now bring this combined software, analytics and data science background to cloud data engineering, designing metadata-driven ingestion frameworks with Azure Data Factory and Azure Data Lake Storage Gen2.

- Building metadata-driven ingestion pipelines with full and incremental loads
- Designing audit logging, watermark management and failure handling for production-style pipelines
- Currently expanding into Azure Databricks, Delta Lake and Microsoft Fabric
